\section{Entropy-Inflation Program Status}\label{sec:entropy-inflation-program}

This section records the implemented entropy-via-inflation bridge, its minimality witnesses, and several natural extensions.

\subsection{Available Machinery}

\begin{itemize}
\item Static decision core: \texttt{DecisionProblem}, \texttt{Opt}, \texttt{numOptClasses}, \texttt{quotientEntropy}, and entropy-rank inequalities.
\item Physical/cosmological layer: discrete-time and locality modules, plus temporal cardinality growth in \texttt{TemporalCountingGap.lean}.
\item Thermodynamic bridge: \texttt{energy\_ge\_kbt\_nat\_entropy} and related floor theorems.
\item Stochastic/sequential layer: PP/PSPACE hierarchy plus newly added set-valued stochastic bridge module.
\end{itemize}

\subsection{Implemented Bridge Stack}

\paragraph{Dynamic family core.}
The module \texttt{InflationEntropyBridge.lean} now contains:
\begin{itemize}
\item \texttt{classes\_monotone}, \texttt{entropy\_monotone}
\item \texttt{classes\_strict\_increase}, \texttt{entropy\_strict\_increase}
\item \texttt{optCompat\_of\_utilityCompat}
\item \texttt{classes\_monotone\_of\_utilityCompat}, \texttt{entropy\_monotone\_of\_utilityCompat}
\item \texttt{thermal\_floor\_monotone\_of\_classes}, \texttt{thermal\_floor\_strict\_of\_new\_class}
\item \texttt{later\_energy\_floor\_implies\_earlier\_floor}
\end{itemize}
\leanmeta{\LHrng{IEB}{1}{8}.}

\paragraph{Temporal adapter.}
The same module includes \texttt{TemporalUtilityFamily} and transfer lemmas
\texttt{temporal\_classes\_monotone\_of\_utilityCompat} and
\texttt{temporal\_entropy\_monotone\_of\_utilityCompat}, lifting temporal state-cardinality indexing into dynamic decision families.

\paragraph{Probability-necessity layer.}
On the temporally expanded valid successor slice, the same module now proves:
\begin{itemize}
\item \texttt{state\_cardinality\_gt\_one\_of\_positive\_time}
\item \texttt{uniformPrior\_uncertainty\_of\_positive\_time}
\item \texttt{uniformPrior\_nondegenerate\_of\_positive\_time}
\item \texttt{counting\_measure\_not\_probability\_on\_stateAt\_of\_positive\_time}
\item \texttt{cosmological\_expansion\_forces\_probabilistic\_reasoning}
\item \texttt{cosmological\_expansion\_forces\_support\_complete\_probabilistic\_reasoning}
\end{itemize}
This strengthens the earlier bridge from monotone optimizer-class growth to a
theorem that expansion of physically valid successor states forces probability
normalization once raw counting ceases to be a probability measure.

\paragraph{Support-complete semantics and chosen encoding.}
The module now names the support-complete valid-answer semantics explicitly via
\texttt{canonicalValidAnswerSemantics} and proves
\texttt{canonicalValidAnswerSemantics\_identifies\_StateAt}. It also defines a
chosen state-indexed physical-decision encoding and proves
\texttt{stateIndexedPhysicalEncoding\_identifies\_StateAt}, making the physical
answer carrier explicit at the level of the temporal slice.

\paragraph{Minimality witnesses.}
The module \texttt{InflationEntropyMinimality.lean} now includes explicit witnesses for:
\begin{itemize}
\item structural compatibility/strictness: \texttt{not\_redundant\_A2\_for\_mono\_classes}, \texttt{not\_redundant\_A3\_for\_strict\_entropy}
\item positivity/floor assumptions: \texttt{not\_redundant\_P1\_for\_positive\_floor}, \texttt{not\_redundant\_P2\_for\_positive\_floor}, \texttt{not\_redundant\_P3\_for\_energy\_from\_entropy\_bridge}
\item weakened-framework requirement witnesses: \texttt{not\_redundant\_A1\_for\_mono\_classes\_weak},
\texttt{not\_redundant\_F1\_for\_finite\_counting\_requirement},
\texttt{not\_redundant\_F2\_for\_numOptClasses\_pos}
\end{itemize}
\leanmeta{\LHrng{IEB}{9}{16}.}

\subsection{Stochastic Set-Valued Alignment}

To reduce static/stochastic semantic friction, the module
\texttt{StochasticSequential/SetValued.lean} adds:
\begin{itemize}
\item \texttt{StochasticSetSufficient} (ties allowed)
\item \texttt{stochasticSetSufficient\_universal}
\item \texttt{stochasticSufficient\_implies\_setSufficient}
\end{itemize}
\leanmeta{\LHrng{SSV}{1}{3}.}
This provides a set-valued baseline in the stochastic regime while preserving the existing singleton-oriented notion.
