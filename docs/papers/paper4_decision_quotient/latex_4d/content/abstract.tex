Exact relevance certification asks which coordinates are necessary to determine the optimal action in a coordinate-structured decision problem. We first give a positive structural consolidation: the tractable families studied here split into core mechanisms, regime lifts, and degenerate collapses, yielding a finite primitive basis. We then prove a maximal realizability barrier: arbitrary labeling kernels are optimizer-realizable, so quotient shape alone cannot characterize a tractability frontier.

The main new result is a meta-impossibility theorem for a principled admissibility class. Admissible predicates are required to be polynomial-time checkable, structural, and invariant under closure laws already forced by exact-certification semantics (relabelings, positive affine transformations, and duplication/irrelevance operations). Closure-law invariance in this class is grounded not only in those internal closure laws, but also in structural convergence: zero-distortion summaries, quotient entropy bounds, and Fisher-style support counts already factor through the same optimizer-quotient core. Within this class, we build explicit same-orbit disagreement witnesses for four obstruction families---dominant-pair concentration, margin masking, ghost-action concentration, and additive/statewise offset concentration. Each witness uses an action-independent, pair-targeted affine term to move within a closure orbit while changing obstruction status. Consequently, no admissible normalization predicate can provide an exact tractability characterization over these families. This yields an admissible-collapse theorem and places the frontier program in a Rice/Arrow-style meta-impossibility tradition: once structural invariances are accepted, the sought classifier cannot exist in the naive finite form.
