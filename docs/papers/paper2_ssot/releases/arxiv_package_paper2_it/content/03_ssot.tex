\section{Derivation as the Capacity-Achieving Structure}\label{sec:ssot}
%==============================================================================

Section~\ref{sec:foundations} identifies the sharp threshold: exact consistency is guaranteed only at independent rate $1$. Here the corresponding structure is \emph{derivation}: one location carries the independent value, while all other representations are deterministic views of that source.

\subsection{Rate 1 as the Exact-Consistency Regime}\label{sec:ssot-def}

\begin{definition}[Optimal Encoding (Unit Independent Rate)]\label{def:ssot}
An encoding system $C$ achieves the \emph{optimal encoding rate} for fact $F$ iff
\[
\text{DOF}(C,F)=1.
\]
\end{definition}

Rate $1$ is the unique independent rate compatible with zero incoherence in the model. A single authoritative source with deterministic views is the corresponding structural form.

\begin{corollary}[Unit Rate Guarantees Determinacy]\label{thm:ssot-determinate}
If $\text{DOF}(C,F)=1$, then the value of $F$ is determinate in every reachable state.
\end{corollary}

\begin{corollary}[Unit Rate Achieves $O(1)$ Update]\label{thm:ssot-optimal}
If $\text{DOF}(C,F)=1$, then coherence restoration requires $O(1)$ manual updates.
\end{corollary}

\begin{corollary}[Uniqueness of the Optimal Rate]\label{thm:ssot-unique}
DOF $=1$ is the unique rate guaranteeing exact consistency.
\end{corollary}

\begin{corollary}[Incoherence Under Redundancy]\label{cor:no-redundancy}
If $\text{DOF}(C,F)>1$, then incoherent states are reachable.
\end{corollary}

\begin{proof}
Immediate from Theorem~\ref{thm:dof-gt-one-incoherence}.
\end{proof}

\subsection{Counting Converse Interpretation}\label{sec:info-sketches}

The threshold and the converse fit together in a compact way.
\begin{itemize}
\tightlist
\item When ambiguity classes are trivial, no auxiliary information is needed and rate $1$ suffices.
\item When a nontrivial ambiguity class survives the observation transcript, Theorem~\ref{thm:fano-converse} shows that exact recovery requires a sufficiently large side-information alphabet.
\item If that side information is unavailable but exact correctness is still demanded, the architecture must rely on additional independently accessible support, which moves the system above the rate-$1$ regime and leads to the update-cost lower bound of Section~\ref{sec:bounds}.
\end{itemize}

Derivation is therefore the capacity-achieving dependence structure: it removes independent rate without removing observable views.

\subsection{Rate--Complexity Tradeoff}\label{sec:ssot-vs-m}

The benefit of derivation is operational. An encoding may expose many visible copies of a fact, but only the independent copies govern manual synchronization cost.

\begin{itemize}
\tightlist
\item \textbf{Independent rate $1$:} one manual update changes the authoritative source; all derived views follow automatically.
\item \textbf{Independent rate above $1$:} each independent location must be synchronized manually to restore coherence.
\end{itemize}

This is the architectural meaning of the threshold: independent rate above $1$ creates both ambiguity and manual synchronization burden.

\subsection{Derivation: The Relevant Dependence Structure}\label{sec:derivation}

\begin{definition}[Derivation]\label{def:derivation}
Location $L_{\text{derived}}$ is \emph{derived from} $L_{\text{source}}$ for fact $F$ iff an update to $L_{\text{source}}$ determines the value of $L_{\text{derived}}$ without an additional manual edit.
\end{definition}

Derivation may occur at creation time, build time, commit time, or query time depending on the host system. The abstract point is unchanged: a derived location does not contribute an additional independently writable value for the same fact.

\begin{theorem}[Derivation Preserves Coherence]\label{thm:derivation-excludes}
If $L_{\text{derived}}$ is derived from $L_{\text{source}}$, then $L_{\text{derived}}$ cannot diverge from $L_{\text{source}}$ and does not contribute to DOF.
\end{theorem}
\leanmeta{\LH{DER2}}

\begin{proof}
By Definition~\ref{def:derivation}, the value at $L_{\text{derived}}$ is determined by the value at $L_{\text{source}}$ under admissible updates. There is therefore no reachable state in which the two locations carry incompatible values for the same fact. Since the derived location has no independently writable contribution, it does not increase DOF.
\end{proof}

\begin{corollary}[Derivation Achieves the Threshold]\label{cor:metaprogramming}
If all encodings of $F$ except one are derived from that one, then $\text{DOF}(C,F)=1$ and exact consistency is guaranteed.
\end{corollary}

\begin{proof}
Only one source remains independent; all other encodings are deterministic views. Apply Theorem~\ref{thm:dof-one-coherence}.
\end{proof}

The same dependence structure can be realized in many host systems, but the theorem is purely about deterministic dependence in the abstract encoding model.
