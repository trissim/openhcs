\section{Mechanized Verification Details}

The main theorem chains of this work are machine-checked in Lean 4, and the cited proof modules compile with zero \texttt{sorry} placeholders. The artifact covers the following theorem packages:

\begin{itemize}
\item \textbf{Threshold and Unified-Converse}: Coherence, independent rate, the side-information lower bound, pair injectivity, clique/fiber/global budget bounds, conditional-entropy and decoder-output reformulations, and deterministic data processing.
\item \textbf{Graph and Asymptotic-Capacity}: Explicit confusability graph objects, exact recovery as colorability, strong-power identification for block confusability, Fekete-style asymptotic Shannon capacity, and a fixed Lov\'asz-$\vartheta$ upper theory.
\item \textbf{Equality and SSOT}: The clique-fiber equality theorem, meet-witness sufficient conditions, the fiber-coherence collapse criterion, and the realizability iff theorem.
\item \textbf{Affine Fact-Matroid}: Semantic determination as span membership of coordinate functionals and the identification of minimal determining fact sets with matroid bases.
\end{itemize}
