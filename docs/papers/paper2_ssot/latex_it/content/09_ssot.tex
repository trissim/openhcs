\section{Unit-Rate Boundary Characterization}\label{sec:ssot}
%==============================================================================

An encoding system has \emph{unit independent rate} when $\mathrm{DOF}(C,F)=1$. By Corollary~\ref{thm:coherence-capacity}, this is exactly the regime in which every reachable state remains coherent. Derived views preserve visible multiplicity without increasing independent rate, so the single-source regime is the unique exact-consistency boundary.\leanmeta{\LHrng{COH}{1}{2}, \LH{DER2}, \LH{RAT1}}

When a nontrivial ambiguity class survives the observation transcript, Theorem~\ref{thm:fano-converse} forces additional side information for exact recovery. If exact correctness is still demanded without that side information, the architecture must rely on additional independently accessible support, thereby leaving the rate-$1$ regime. Appendix~\ref{sec:appendix-boundary} contains the detailed derivation lemma and the full boundary proof package.\leanmeta{\LH{CIA3}, \LH{BND2}, \LH{RED1}}
