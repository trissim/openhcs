\section{Predictive Validation}\label{sec:evaluation}

Corollary~\ref{cor:integrity-threshold} states that verifiable structural integrity holds iff both causal propagation and provenance observability hold. This boundary-case criterion makes concrete predictions when instantiated on representative systems. Appendix~\ref{sec:appendix-classification} records the full classification; the main finding is that the majority of common infrastructure falls into patterns that cannot verify integrity. This is an architectural exposure: the host cannot distinguish valid derived states from undetected stale states through its own structural interface.
