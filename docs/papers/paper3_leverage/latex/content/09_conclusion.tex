\subsection{Limitations}

\textbf{1. Canonical-encoding scope:} the main theorems are exact for the canonical binary decision encoding attached to the bounded decision system. Extending the same conclusions to more general physical encodings requires an explicit transport argument.

\textbf{2. Imported hardness regime:} the thermodynamic cost theorems are unconditional, but the stronger no-polynomial-certification claims rely on imported hardness results for the canonical family.

\textbf{3. Calibration choice:} Landauer calibration supplies the physical conversion constant. Stronger substrate-dependent lower bounds are possible, but they belong to a different modeling layer than the one studied here.

\textbf{4. Finite-budget model class:} the no-collapse theorem is a statement about globally bounded budget profiles with positive per-bit cost and exponential lower-bound growth. Different collapse claims require explicit bridges into that profile language.
