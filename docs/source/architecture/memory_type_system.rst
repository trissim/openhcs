Memory types and array conversion
=================================

This page moved when its generic implementation was extracted.
:external+arraybridge:doc:`ArrayBridge <index>` owns memory types and generic
array conversion, plus the decorator metadata keys for callable input, output,
and execution memory. OpenHCS documents only the callable-contract projection,
compiled framework-device plans, runtime adapters, and cross-package invariants
that compose it.

See :doc:`gpu_resource_management` for the OpenHCS planning boundary and
:doc:`external_foundations` for the package ownership policy.
