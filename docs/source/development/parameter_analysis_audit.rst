Parameter analysis audit
========================

This historical audit described the removed Textual form stack. Generic
signature, docstring, and callable-declaration analysis now belongs to
python-introspect, generic Qt form generation belongs to pyqt-reactive, and
OpenHCS owns only its parameter policy and application adapters.

This compatibility route is intentionally orphaned and is not current developer
guidance. Use :doc:`../architecture/external_foundations` and
:doc:`extension_workflows` for the current boundaries. The original audit is
retained under ``docs/archive/development/parameter_analysis_audit.rst``.
