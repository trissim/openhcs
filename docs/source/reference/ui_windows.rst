Desktop window reference
========================

This reference shows every stable OpenHCS desktop window exposed through the
UI bridge. The inventory, titles, capture targets, filenames, and figures are
projected from the registered window identity declarations; this page does not
maintain a separate window list.

Use these figures to recognise a window while working. For task instructions,
continue with :doc:`../guide_for_biologists/basic_interface` and the relevant
:doc:`../user_guide/index` page.
