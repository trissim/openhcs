# Archived documentation

Everything under this directory is superseded history. It is excluded from the
active Sphinx corpus and from `scripts/validate_docs.py`. Titles or status labels
inside archived files— including labels such as “canonical,” “current,” or
“pending”—describe the document at the time it was written and are not current
OpenHCS authority.

Use these active sources instead:

- OpenHCS architecture: `docs/source/architecture/`
- developer extension workflows: `docs/source/development/`
- user and biologist guidance: `docs/source/user_guide/`,
  `docs/source/guide_for_biologists/`, and `docs/source/guides/`
- generic extracted-package behavior: the corresponding package under
  `external/`

Archived plans and audits remain useful for decision history and migration
rationale. Any unfinished checklist in them must be revalidated against current
source and tracked in a current issue or plan before it is treated as work to do.
