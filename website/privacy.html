Public policy

Privacy

This page explains the information boundaries of the OpenHCS website, local software, and planned read-only hosted MCP plugin.

Effective July 27, 2026

Deployment status

OpenHCS does not currently operate a public hosted MCP endpoint. The browser plugin cannot be connected until a production endpoint, deployment operator, retention policy, and service providers are identified. This page does not claim that service is live.

Scope

OpenHCS is an open-source bioimage-analysis project maintained by OpenHCS contributors. This policy covers this public project website and the initial read-only hosted OpenHCS MCP surface if it is deployed.

It does not govern ChatGPT or other OpenAI services, GitHub, PyPI, Read the Docs, Google Fonts, or other linked services. Those providers apply their own privacy terms. Local OpenHCS runs on the user's computer and is not made remotely accessible by visiting this website or installing a browser plugin.

Website data

The OpenHCS website source does not provide user accounts, contact forms, application analytics, advertising trackers, or an OpenHCS cookie. The hosting and network providers may process ordinary request metadata such as IP address, timestamp, requested page, browser type, and security logs as part of serving the site.

Pages currently request font files from Google Fonts, so a visitor's browser may send ordinary request metadata to Google. Following an external link sends the visitor to the named third-party service.

Hosted MCP data

If the hosted MCP service is deployed and a user chooses to connect it, ChatGPT may send the service the tool request needed to answer that user. The initial universal public service is read-only and does not require an OpenHCS account or OAuth token. Deployment infrastructure may process ordinary request and security metadata such as IP address, timestamp, headers, and requested route.

The OpenHCS application-level audit event is deliberately narrow. It contains a timestamp, authentication mode, declared capability name, hosted transport, and outcome. It does not record bearer tokens or tool arguments. Public read-only events do not invent or record a tenant subject. A separately operated private deployment may enable OAuth token introspection and add its configured tenant subject to the event; that operator must disclose its identity and retention terms. The initial hosted capabilities return packaged OpenHCS knowledge, architecture descriptions, function discovery, configuration-schema reflection, and a filtered capability registry.

What the initial hosted surface does not access

  • Files, folders, images, or microscopy datasets on the user's computer.
  • The local OpenHCS GUI, Plate Manager, pipeline editor, Napari, or Fiji.
  • Local pipeline execution, viewers, or other processes on the user's machine.
  • Write operations or arbitrary host paths.

Do not place confidential, patient-identifiable, protected-health, or other regulated data into a hosted-plugin request. The initial read-only service neither needs nor supports that material.

Sharing and retention

The final production operator may use infrastructure, identity, and security providers to deliver and protect the hosted service. The operator, provider list, processing locations, and concrete retention periods must be published here before launch. OpenHCS does not sell personal information or use the hosted MCP audit event for advertising.

Information may also be preserved or disclosed when required to investigate abuse, protect the service, or comply with applicable law.

Your choices

Visiting the source repository or documentation does not require connecting the hosted plugin. A connected user can stop future MCP requests by disconnecting the OpenHCS app in ChatGPT. Requests about access, correction, or deletion of information held by a future hosted operator will be handled through the contact below, subject to the applicable law and the information actually held.

Contact

For a privacy question, contact the OpenHCS maintainer at {{ OPENHCS_CONTACT_EMAIL }}. Do not send microscopy data, access tokens, credentials, or sensitive personal information by email.

For ordinary product support, use the OpenHCS support page.
