ChatGPT web plugin status

The public website and submission package are being prepared, but no public hosted OpenHCS endpoint is currently live. ChatGPT web cannot connect to the local OpenHCS application or its STDIO MCP server. The intended first web endpoint is a universal, unauthenticated, read-only discovery surface; private OAuth deployments are a separate operating mode.

What to include in a report

  • Whether the problem is in ChatGPT web, ChatGPT desktop, Codex, the OpenHCS GUI, or a headless installation.
  • The OpenHCS version, operating system, Python version, and installation route where relevant.
  • The smallest sequence that reproduces the problem and the exact error text.
  • Whether the issue affects the local MCP server or a separately hosted endpoint.

Remove credentials, bearer tokens, patient identifiers, microscopy data, private paths, and other sensitive information before posting to the public issue tracker.

Know which surface you are using

Surface Available boundary Not available
Local desktop MCP Installed OpenHCS declarations plus explicitly configured local UI, viewer, file, and execution access. Remote access merely because the package was installed.
Planned ChatGPT web plugin Universal no-account access to read-only packaged knowledge, architecture, function discovery, schemas, and capability registry. Local files, microscopy images, GUI, viewers, pipeline execution, or the user's computer.
