Install your way.

Use a desktop installer with no Python setup and one-click local agent connection, or install from PyPI for headless systems and custom environments.

Desktop installers No Python setup required
GitHub release
Win Download for WindowsDownload and run — no ZIP to extract ↓ mac Download for macOSOpen the DMG, then open OpenHCS Installer ↓

User-scoped, CPU-only installation with CellProfiler compatibility, local MCP, Napari, and Fiji/Bio-Formats support. Leave the agent option checked to connect ChatGPT desktop, Codex, and detected supported local clients, then restart the clients and ask them to use OpenHCS. ChatGPT web requires a remote HTTPS app or an eligible Secure MCP Tunnel. GPU libraries are not included. Fiji Java components are resolved on first use. Initial assets are not code-signed, and the macOS app is not notarized, so your OS may ask you to confirm trust.
