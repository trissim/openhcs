same mental model.

The local MCP server is implemented and tested in the current development tree, but it is not included in the stable 0.5.21 wheel. The public MCP extra, signed Claude package, registry listing, and hosted connector remain release work—not services we claim are already available.

  • 02 Codex configuration and Claude packaging prepared for release
  • 03 Explicit read/write roots for microscopy data and outputs
