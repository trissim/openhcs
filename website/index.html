Through MCP it can construct and validate the same typed pipeline used by the desktop application, run it locally, and inspect the results without manually constructing the pipeline. Workflow evidence

One prompt, one executable workflow

Starting from one prompt and a public NeuronCyto II crossover field, Codex projected two loose TIFF planes into biological channels, built and compiled a pipeline in the live desktop, and ran a per-neuron morphology analysis. The unattended run produced persistent images, ROIs, SWC morphology, measurements, and a settled Napari feature table. Visual QA then exposed a clustered crossover-tracing defect. After the generic tracing fix, the recaptured result shows 9 neurons and 24 spatial-graph paths, with table selection linked to the highlighted neuron. The generated Python remained editable in OpenHCS.

Installation

Desktop installers include the GUI and local MCP setup. Use PyPI for headless systems, GPU libraries, or an existing Python environment.

Desktop installers No Python setup required
GitHub release
Download for WindowsDownload and run — no ZIP to extract ↓ Download for macOSOpen the DMG, then open OpenHCS Installer ↓

User-scoped, CPU-only installers include CellProfiler compatibility, local MCP, Napari, Fiji, and Bio-Formats. GPU libraries are optional and not included; Fiji downloads Java on first use. The latest complete GitHub release may trail PyPI. The Windows installer is unsigned, and the macOS installer is not notarized, so the OS may ask you to confirm trust. See Support for the separate ChatGPT web setup.
